## Resumo do trabalho

Este trabalho consistiu no desenvolvimento de um programa em Python para a gestão de alunos de uma turma, através de um menu interativo. Os dados são armazenados numa lista de tuplos, incluindo o nome, o identificador e as notas dos trabalhos de casa, projeto e teste.
O programa permite adicionar alunos, consultar os seus dados por identificador e visualizar a turma completa. Inclui ainda funcionalidades de gravação e leitura de ficheiros de texto, utilizando o símbolo # como separador. O código encontra-se organizado em funções, facilitando a sua estrutura e funcionamento.
