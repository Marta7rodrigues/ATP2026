## Resumo do trabalho
Foi me proposta a realização de um tpc, a qual tive de criar uma aplicação em Python com um menu interativo de opções (0 a 9) para gerir e analisar uma lista de números. O programa que realizei permite criar listas (de forma automática ou manual), calcular a soma, média, maior e menor elemento, verificar se está ordenada, procurar elementos e terminar o programa mostrando a lista final.
